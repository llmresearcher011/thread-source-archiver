# Safety and Source Use

AetherMind Source Archiver is intended for public, source-grounded research workflows.

## Do not use personal platform credentials

This project should not require or store:

- X/Twitter usernames or passwords
- 2FA codes
- browser cookies
- `auth_token`
- `ct0`
- browser session exports

## Use public and permitted data sources

Use this tool only with data you are allowed to process. Respect platform terms, provider limits, rate limits, robots policies where applicable, and applicable law.

## Keep raw source attribution

The normalized output preserves source URLs, post IDs, timestamps, and raw records so downstream systems can cite and audit evidence.
